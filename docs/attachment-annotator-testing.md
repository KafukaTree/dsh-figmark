# 附图标注 · 独立测试版

本功能在 `feat/attachment-annotator`，直接基于远端 main `751ffaf4`。与之前的 `send-card-review` 分开评审；这里没有新增队列、智能体调用、系统提示词或消息发送拦截。

## 使用

1. 在 DSH 输入框添加图片，直接点击原生缩略图。该图片会在居中浮层中打开；输入框上方没有额外入口，也不会切换侧栏。
2. 工具条贴在图片右侧，提供选择、画笔、箭头、矩形、椭圆、Pin 评论、颜色、撤销/重做和缩放。
3. Pin 或形状绘制后，评论输入框以原版单胶囊样式出现在标记旁边，不带标题栏或底部按钮；点击标记编号或双击标记可重新编辑，Escape 收起，Delete/Backspace 删除选中标记。画笔可连续绘制。
4. 点击「加入输入框」会新增一张带批注的 PNG，并把逐条编号和评论追加到现有草稿，然后关闭浮层；原图保持不变。确认输入框中的新附件和评论文字后，自行按 DSH 的发送按钮。
5. 需要独立文件时点「下载 PNG」；Pin 评论会写在导出图底部。宿主缺少副本接口时仍可下载；原附件在生成期间被移除或开始发送时，浮层自动关闭且旧结果不会回填。
6. 关闭按钮先结束编辑。已有批注时需要在浮层内再次确认「放弃批注」；原附件被移除、发送中、切换会话或卸载插件时，浮层自动清理且不会回填旧结果。

## 必测

- PNG/JPEG/含中文评论；SVG 附件如果宿主将其归为普通文件，则本入口不适用，可先转 PNG。
- 点击目标缩略图只打开浮层，不打开原生 lightbox；点击其他图片仍打开原生 lightbox。
- 「加入输入框」后的草稿包含与图片编号一致的评论摘要；已有草稿文字不得丢失，写草稿失败时新附件应撤回。
- 连续画笔、Pin 后立即输入、双击标记定位评论、移动/缩放矩形、改色、撤销/重做。
- 宽/窄窗口、200%/400% 放大后滚动、源图四角位置是否一致；图片外围不应出现额外卡片边框，底部只保留两个小按钮，悬浮工具栏不能遮住唯一可操作区域。
- 除「加入输入框」明确追加评论摘要外，不修改草稿中的文本、引用和其他附件；打开/画图/关闭/下载均不产生会话消息。
- 生成过程中删除原附件、切换会话、关闭浮层或点击发送：旧结果不得回填其他会话、恢复已经发送的附件或另起一轮请求。
- 普通会话和子智能体续接都测：加入副本后，仅由原生发送流程发送一次。副本用宿主 inline image draft，不建立插件上传队列。
- 加入副本失败时原图仍在，批注仍能下载；重复点击不重复加入。编辑评论后可明确生成新版本。
- 打开另一张图片不会覆盖未完成批注；同一会话可继续。脏批注的关闭需要再次确认。
- 原生图片预览/拖放/删除/上传重试、旧图片/SVG/PDF/本机网页批注，以及既有发送卡片保持原有行为。
- 卸载/重载插件后新浮层移除；原生附件不应被释放或改写。

## 已验证与限制

附图编辑的既有行为测试已改成浮层测试，并增加缩略图桥接、生命周期、异步过期与几何分支。真实 React DOM/Canvas 的指针、键盘和输入事件均走现有测试环境；typecheck、lint、逐文件四项 100% coverage 与构建契约必须全部通过。另用独立的 MuPDF SVG 渲染器验证原图、Pin、矩形和评论图例的合成输出。

本环境无法完成真实 Chromium 验证时，不要将此包当成已通过宿主实测的发布版。开发版应先在隔离网页 profile 验证，再安装桌面版并检查上述用例。

当前只保留一张图的临时可编辑图层；刷新/卸载或明确清除后不保留图层。导出的 PNG 是静态副本。动图暂未冻结，建议首轮用静态图片。PNG 最大边 8192、最大 1600 万像素，大图会等比例缩小，透明区域按已有导出器合成白底。原图文件始终保留。

## 同包的独立 SVG 发送修复

Visio 图可以批注却无法发送的一处原因是：旧导出器移除 SVG 根标签后，丢失根上的 `xmlns:v` 等命名空间声明，PNG 合成前就产生 XML 错误。修复保留已清理的根标签、继承样式和命名空间，只更新导出视口。新增测试验证结构合法以及发送按钮流程。原始 SVG 不需要修改。

此修复在 `fix/svg-export-namespaces` 上有独立提交，可单独评审；同包的预构建版本同时包含它和附图编辑功能。
